# Google Meet Agent

A Spring Boot application that provides automated agent functionality for Google Meet sessions.

## Features

- Automated meeting participation and monitoring
- Real-time meeting analytics and insights
- Integration with Google Meet API
- Configurable agent behaviors
- Meeting transcription and summary generation
- Participant management and notifications

## Technology Stack

- **Java** - Core programming language
- **Maven** - Build and dependency management
- **Google Meet API** - Meeting integration
- **Spring Security** - Authentication and authorization

## Prerequisites

- Java 11 or higher
- Maven 3.6+
- Google Cloud Platform account with Meet API access
- Google OAuth 2.0 credentials
